# 模型分工报告

仅当当前用户请求明确调用 `$yiwan-sol-advisor`，并按该 Skill 流程处理当前任务时，才在最终回复末尾追加模型分工报告。

仅仅安装、更新、讨论、审查或排查 `yiwan-sol-advisor` 本身，不视为调用该 Skill，不显示模型分工。

只报告当前 Skill 运行中实际观察到的运行时活动。静态配置、提示词或预期路由不能作为模型实际使用的证明。某个阶段没有运行时必须如实说明，不得编造。

```text
模型分工：
- Sol（继承用户当前 Codex 模型与推理挡位）：说明实际完成的需求分析、架构、五段式 Spec、修正规划、父级验证和最终验收；未运行的职责不得编造。
- Gemini 3.8 Flash High（或指定实现模型）：说明实际完成的代码实施、文件修改和测试；未成功派发或被权限阻止时必须如实说明。
- fresh Sol（继承用户当前 Codex 模型与推理挡位）：说明实际完成的独立只读审查及最终 verdict；未运行时必须明确说明。
- 其他模型：正常情况下写“未使用”；如果实际使用，必须列出模型、任务和原因。
```
